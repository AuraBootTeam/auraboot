# Optional agent module preparation

This module establishes the future agent-to-core dependency direction in the
existing OSS repository. During assembly preparation, AI source and resources
remain in root so existing application behavior is preserved.

The module is not yet an extracted agent implementation and is not published.
Do not use its presence as proof of an AI-free core or independently usable agent
artifact. Implementation, resource and test ownership move together in the next
extraction slice; no framework replacement or capability removal is involved.
